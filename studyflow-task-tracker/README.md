# StudyFlow Task Tracker

StudyFlow is a private React application for organising study tasks, deadlines, priorities, and completion progress. It is designed as a focused, accessible project for practising real React state and interaction decisions.

## Commands

```bash
npm ci
npm run dev
npm test
npm run lint
npm run build
```

Node.js 20 is required. Tasks are stored locally in the browser and no external credentials or services are needed.

## Accessibility

StudyFlow uses native form controls, visible labels, keyboard-operable filters, focus indicators, non-colour status text, and polite live announcements for task changes.
